# Política de Segurança do Repositório

## Notificação de Vulnerabilidades
Se identificar uma vulnerabilidade de segurança neste projeto, abra um GitHub Security Advisory privado ou contate o autor diretamente.
NUNCA publique credenciais ou crie issues públicas para falhas de segurança.

## Boas Práticas
- Chaves e credenciais jamais devem ser commitadas no código.
- Utilize sempre variáveis de ambiente externalizadas.
